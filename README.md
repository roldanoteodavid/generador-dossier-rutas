# Generador de Dossier de Rutas Scout ⚜️

Herramienta diseñada para automatizar la segmentación y el cálculo de tiempos de rutas de montaña a partir de archivos GPX, siguiendo la metodología de la **Escuela de Montañismo (EDM)** y el sistema **MIDE**.

## 🚀 Sobre el proyecto
Este proyecto ha sido desarrollado por **Jorge Peña** y **David Roldán**, monitores del **Grupo Scout Orión-B 723**, con el fin de facilitar la tarea de elaboración del dossier de rutas.

La aplicación permite subir un archivo `.gpx`, divide la ruta automáticamente en tramos y calcula los tiempos estimados según la rama y preparación física. Solo queda copiar los resultados al dossier.
